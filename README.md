# 🔐 Password Manager & Secure Notes

A privacy-focused mobile application for securely managing passwords and storing personal notes.

The application is designed with a **local-first security approach**, where all user data is stored only on the device. No passwords, notes, or personal information are transmitted to external servers or stored in the cloud.

---

## 📱 Features

### 🔑 Password Manager

* Securely store and manage account credentials.
* Organize passwords for quick access.
* Keep sensitive login information available only on your device.

### 📝 Secure Notes

* Create and manage private notes.
* Store confidential information locally.
* Keep personal data away from third-party services.

### 🔒 Privacy & Security

* ✅ Local-only data storage.
* ✅ No cloud synchronization.
* ✅ No external database.
* ✅ No internet data transmission.
* ✅ No user account required.
* ✅ Your data stays on your device.

---

## 🏗️ Application Architecture

The application follows a privacy-first architecture:

```
User Data
    |
    ↓
Local Device Storage
    |
    ↓
Encrypted / Protected Application Data
```

There is no dependency on external servers, APIs, or cloud storage.

## 📲 Installation

1. Download the latest release from the GitHub Releases page.

3. Open the application and start managing your passwords and notes securely.

> Make sure installation from unknown sources is enabled if required by your device settings.

## 🔐 Security Considerations

This application is designed to minimize data exposure by keeping all information locally.

For better protection:

* Use a strong device lock password.
* Enable biometric protection if supported.
* Keep your device operating system updated.
* Avoid sharing application data files with untrusted sources.
